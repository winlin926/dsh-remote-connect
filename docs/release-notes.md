手机扫一次码，就能接着用电脑上的 DSH。手机和电脑在同一个局域网时走局域网，出门走公网。一条断了会自动换另一条，换回来还是原来那个会话，不用重新扫码，也不用再批准。

## 这次更新

- 面板上还是一个二维码，局域网和公网共用。局域网通就用局域网，配好公网就用公网；公网进不去时自动换回局域网的码，新手机照样能扫。
- 用公网域名打开的页面，会顺手在局域网里建一条直连。哪条快用哪条，卡住或断了自动换，也能在「连接设置」里指定先走哪条。
- 聊天、回复、传文件、看文件都能走直连；支持 Service Worker 的 HTTPS 页面，公网断了也能直接打开工作区里的 HTML 预览。
- 自托管节点也有两条线，电脑上能看到每台手机正在走哪条。
- 手机的重连提示收成顶部一个小 Wi‑Fi 图标加一行字，跟随深浅主题；电脑面板的「已复制」「已刷新」显示在按钮旁边。

## 修复

- 公网断开后切局域网，不会再卡在回退那一步。
- 一个节点接了多台电脑时，请求只发给配对的那台，不会串。
- 电脑和节点短暂断开时，不会再漏掉设备撤销通知。
- 手机授权失效后，直接提示去电脑上重新扫码，不再显示「重新连接」让人反复刷。
- 插件更新检查或安装失败时只显示一行原因，不再用整段报错占满面板。

旧版自托管节点还能走公网；想用双线路切换，插件和节点都要升到 0.7.0。
