# 0.6.0

适配 DSH 0.2.2 系列，验证基线为 0.2.2-rc.3；需要 Node.js 24.9+。

- 公网连接统一为节点管理：添加、检测、切换和删除固定域名网关或自托管服务节点。
- 新增自托管 `remote-server`：Host 主动连出反向隧道，同一节点可服务多台电脑，转发手机的 HTTP、SSE 和 WebSocket 流量。
- 节点发现使用协议 v2，区分节点身份与主机身份；身份变化时暂停连接，待本机确认后恢复。继续识别协议 v1 节点。
- 公网配对在手机和电脑两端确认主机指纹；删除自托管节点时撤销节点侧的主机注册。
- 局域网支持域名 HTTPS，增加启动诊断与经身份核对的同机局域网回退。
- 本机面板通过 DSH 官方插件管理器检查和安装更新；安装后需要重启时会明确提示。
- 移除未接入的 WebRTC、TURN 和独立控制面；清理无调用代码和过时文档，收紧包内容检查，CI 同时验证插件与服务端。

已授权手机拥有与本机相近的权限。公网节点终止 TLS，运营者可以看到转发内容；本项目不提供端到端加密，也不运营公共节点。

真实手机、真实公网节点、真实域名证书签发仍需部署环境验收；桌面浏览器和本机集成测试不代表这些场景已通过。
