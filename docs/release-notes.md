手机扫一次码，就能接着用电脑上的 DSH。在同一 Wi‑Fi 下可以走局域网，出门可以走公网。只要备用线路还能连到同一台电脑，短暂重连后就能回到原会话，无需重新扫码或批准配对。

## 主要更新

[1] 「远程控制」面板只显示一个二维码。新装默认使用局域网。配好公网入口并通过检测后，扫码会打开公网地址。公网入口不可用时，面板会在原位置显示局域网码，同一 Wi‑Fi 下的新设备可以扫这个码配对。

[2] 通过公网域名打开 DSH 后，如果手机和电脑在同一 Wi‑Fi 下，页面会尝试建立局域网直连，浏览器仍显示原来的域名。当前线路持续卡顿或断开时，会尝试切换到已验证的备用线路。默认局域网优先，也可以在「连接设置」里改为公网优先。

[3] 聊天请求、流式回复、文件上传和普通文件预览可以走直连。在支持 Service Worker 的 HTTPS 页面上，公网断开后也能通过已建立的直连打开工作区 HTML 预览。

[4] 自托管公网节点也支持双线路。电脑的已授权设备列表会显示每台在线手机实际使用的线路，方便看出哪些设备走局域网、哪些走公网。

[5] 手机的重连和切换提示改为顶部两侧栏按钮之间的小 Wi‑Fi 图标和一行文字，背景透明，跟随 DSH 深浅主题。电脑面板的「已复制」「已刷新」直接显示在对应按钮旁。

## 修复

[1] 修复了公网断开后，旧版回退仍要通过公网确认局域网地址，可能卡在回退步骤的问题。双线路会话会提前验证备用直连。

[2] 修复了自托管节点接入多台电脑时，已配对电脑离线后，请求可能被转给另一台在线电脑的问题。现在节点只向该会话配对的电脑转发。

[3] 修复了电脑与自托管节点暂时断开时，可能漏收设备撤销通知的问题。节点重连时会补发撤销记录，收回该设备的公网和直连权限。

[4] 修复了设备授权失效后仍显示「重新连接」、容易让人反复刷新的问题。现在会直接提示去电脑上的「远程控制」重新扫码。

[5] 修复了检查或安装插件更新失败时，整段运行时错误挤占面板的问题。现在只显示一行关键原因，缺少内置 pnpm 时会提示如何处理。

## 升级

```powershell
dsh plugin --profile <你的 profile> add @winlin926/dsh-carry@0.7.0
```

或者在 DSH 插件页点更新，更新完重启宿主。

旧版自托管节点可以继续走公网。通过自托管节点使用双线路切换，需要同时升级插件和节点。
