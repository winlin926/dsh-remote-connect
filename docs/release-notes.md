公网连接不再误报「证书或域名错误」：连接一直是好的，出错的是检测结果的判断和上屏。

## 修复

1. 后台每两分钟探一次公网入口，只要一次 TLS 握手被中断，就被当成证书问题，面板和顶部提示都报「公网入口的证书或域名错误，请检查 HTTPS 证书和域名解析」，手动点一次检测又恢复正常。现在只有证书本身有问题（过期、自签、域名不匹配、证书链不被信任）才这么报，握手中断按连不上处理。
2. 检测失败会立刻再探一次，连续两次都失败才把结论写到面板上。网络抖一下不会再弹提示。
