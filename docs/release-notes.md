# 0.6.0 稳定版

适配 DSH 0.2.2 系列，需要 Node.js 24.9 或更高版本。相较 0.5.0，本次重点完善公网连接管理、节点身份校验和自托管能力。

## 主要变化

- **新增节点管理与自托管**：统一添加、检测、切换和删除公网节点；新增 `remote-server` 反向隧道，一个服务节点可连接多台电脑，同时兼容旧版 v1 网关。
- **修正节点身份校验**：v2 协议将服务节点身份与电脑主机身份分开验证。节点身份变化时暂停连接并要求本机确认，避免在身份不一致时继续连接。
- **修正主机配对与节点清理**：手机和电脑分别核对目标主机指纹；删除自托管节点时同时注销对应电脑的服务端注册，避免留下失效注册。
- **增强局域网连接**：支持域名 HTTPS 和启动配置诊断；公网连接中断后，只有确认主机指纹一致才回退到局域网地址。
- **简化更新与维护**：从远程连接面板检查更新，并由 DSH 官方插件管理器安装；移除未接入产品流程的 WebRTC、TURN 和独立控制面。

## 从 0.5.0 升级

原有局域网授权可以继续使用；通过旧公网入口授权的设备需要重新扫码配对。自托管部署见[服务节点指南](https://github.com/winlin926/dsh-remote-connect/blob/v0.6.0/docs/self-host.md)。

## 安全说明

已配对手机拥有与电脑本机相近的操作权限。公网节点会终止 TLS 并转发请求，节点或隧道运营者可能看到转发内容；本项目不提供端到端加密，也不运营公共节点。请只使用信任的节点。
