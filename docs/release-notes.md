手机扫一次码，就能接着用电脑上的 DSH。手机和电脑在同一局域网时走局域网，出门走公网。只要备用线路还能连到同一台电脑，短暂重连后就能回到原会话，无需重新扫码或批准配对。

## 主要更新

[1] 「远程控制」面板现在只显示一个二维码。局域网和公网共用同一个码，系统自动选择可用的入口。首次公网配对会核对主机指纹，之后两条线路可以自动切换。

[2] 通过公网域名打开 DSH 后，如果手机和电脑在同一局域网，会自动建立局域网直连。线路卡顿或断开时会切换到备用线路。默认局域网优先，也可以改为公网优先。

[3] 聊天、回复、文件上传和预览都能走直连。HTTPS 页面支持 Service Worker 的话，公网暂时断掉也能通过已有直连继续看 HTML 预览。

[4] 自托管公网节点也有双线路。电脑的已授权设备列表能看到每台手机用的是局域网还是公网。

[5] 手机的重连和切换提示改成顶部的一个小 Wi-Fi 图标加一行字，背景透明、跟随深浅主题。电脑面板的「已复制」「已刷新」直接显示在按钮旁。

## 修复

[1] 修复了公网断开后旧版可能卡在回退步骤的问题。双线路现在提前验证备用直连。

[2] 修复了自托管节点接多台电脑时，请求被转给其他电脑的问题。现在只转给配对的那台。

[3] 修复了电脑与节点暂时断开时漏掉撤销通知的问题。重连时会补发撤销记录。

[4] 修复了授权失效还显示「重新连接」导致反复刷新的问题。现在直接提示去电脑上重新扫码。

[5] 修复了插件更新检查或安装失败时用整段报错挤占面板的问题。现在只显示一行主要原因。

## 升级

`0.7.0` 的 `.tgz` 安装包可在本 Release 的附件中下载，暂未发布到 npm。安装后请重启 DSH。

旧版自托管节点可以继续走公网。通过自托管节点使用双线路切换，需要同时升级插件和节点。
