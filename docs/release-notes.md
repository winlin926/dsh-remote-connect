本次更新重做了手机端的启动页面，打开远程连接就能看出它是在加载还是卡住。

## 变更

**新的启动页面**。打开远程连接是一个全屏启动页，和电脑上 DSH 主界面同一套黑白配色，跟随系统明暗。页面显示当前阶段、加载了几个模块和真实进度，完成后提示「启动完成」并淡出，不挡操作。

之前启动时只有屏幕底部一行小字，容易被当成没反应；现在整页都能看出进度。加载失败时会收起启动页，给出失败提示和重新加载按钮。

**版本号 0.6.2 → 0.6.3**。插件、`remote-server` 与公网节点示例同步。运行时标识不变：插件内部 ID 仍是 `copylee-remote-control`，管理接口仍是 `/api/dsh-remote-connect/manage`，存储目录仍是 `~/.dsh/dsh-remote-connect/<profile>`，升级不需要重新配对、不需要重建节点。

**README**。重写为安装、快速开始和功能介绍，中英双语同步。

## 升级

```powershell
dsh plugin --profile <你的 profile> add @winlin926/dsh-carry@latest
```

或在 DSH 插件页对已安装的 dsh-carry 点更新。更新后重启宿主，手机浏览器下次进入时会显示新的启动页面。
