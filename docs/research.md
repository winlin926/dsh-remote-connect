# 固定公网连接实现边界

当前版本不使用免费临时公共隧道。“任意网络”通过用户自己的固定 HTTPS 域名与 frpc / 反向代理到达本机认证网关。

- 链路：手机 → 固定域名 → 用户的 frps / 反向代理 → 本机 `127.0.0.1:43128`。
- 插件不配置 DNS、日本节点或 frpc，不修改系统代理和系统服务。
- 固定域名只接受无路径、无用户信息的 HTTPS origin；Host 必须在允许列表中。
- 公网新设备先验证 6 位密码，再由电脑批准；设备授权与密码验证是两个独立条件。
- 密码错误采用来源地址与全局限速，密码变更撤销旧设备并清理临时入口。
- 域名检测要求当前网关身份，而不是任意 HTTP 成功响应。
- ACME HTTP-01 只提供单层挑战文件。证书按 SakuraFrp 约定部署；自动续期前重新检查当前域名和公网监听状态。
- 电脑代理只用于域名检测与 ACME 请求，不影响手机流量路径。
- 首次迁移旧 `dsh-roam` 的域名、固定密码和 ACME 账户状态；原目录不删除、不改写。
- SSE 通过认证 WebSocket 载体转发，手机自定义界面与原生界面不因公网实现而改变。

固定域名、密码和证书实现参考 `dsh-roam`，电脑面板、设备配对、网关及手机界面继续以 `dsh-remote-control` 为主体。
