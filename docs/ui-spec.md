# 远程连接 UI 约定

本文件只约束本插件的管理面板、启动页、配对页、拒绝页和宿主不可用页。聊天、自动化与宿主设置使用 DSH 自身界面。

## 主题与颜色

面板读取宿主的正文、背景、描边和状态变量。主操作统一使用陶土橙 `#D97757`，文字为白色；不提供全局配色切换，不修改其他插件的颜色。

启动页使用 DSH 同源鲸鱼和浏览器的 `Canvas`、`CanvasText`、`GrayText`。默认跟随系统，顶部手动切换只影响当前浏览器内的启动页，不改宿主主题。宿主挂载后立刻移除主题控件；启动层本身不拦截点击。

自有页面使用以下中性色，并跟随系统深浅色：

| 语义 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#FFFFFF` | `#151517` |
| 正文 | `#0F1115` | `#F9FAFB` |
| 次要文字 | `#61666B` | `#ADB2B8` |
| 描边 | `rgba(0,0,0,.12)` | `rgba(255,255,255,.16)` |
| 输入背景 | `#F5F6F7` | `#353638` |

二维码保持白底深色码点。危险、成功和警告使用语义色，并配文字说明。
对话框与关闭按钮共享背景、正文变量，深浅色均保持可读；连接方式按钮显式使用本插件文字色，避免继承宿主按钮颜色。

## 布局与交互

- 管理面板宽屏双列，窄屏单列；不出现整页横向溢出。
- 侧栏入口使用官方底部插槽，不查询或搬移宿主私有 DOM。
- 手机主要触控目标至少 44px，输入框不被软键盘遮挡；面板跟随 visualViewport 调整。
- 弹窗有可访问名称、明确关闭入口和初始焦点；使用原生 dialog 管理模态焦点。
- 网络错误保留可继续的配对进度，重试不重新创建已经存在的配对请求。
- 面板状态轮询不重叠，页面隐藏时暂停，恢复可见时刷新。审批、发送消息等写操作不自动重放。
- 局域网 HTTP 下复制提供兼容方式；只有实际复制成功才提示成功。
- 复制失败展示本次请求的实际内容，配对链接不与其他内容混用；中文组合输入期间 Enter 不提交重命名。
- 域名、节点指纹确认、首次配对确认与证书管理只在本机开放。
- 公网首次配对页按顺序显示节点名称、类型、协议版本与主机指纹，“确认是本机”后才发起配对；本机面板显示同一设备名与同一指纹后再确认。

## 验证边界

用 `pnpm preview:boot` 打开独立启动页预览，顶部可切换系统、亮色和暗色，底部可停在任一启动阶段。预览和正式页面共用渲染组件，只有预览使用示例计数；正式页面的分子只来自宿主实际注册的模块。

按修改影响检查深浅色、窄屏、长设备名和地址、键盘与错误恢复。浏览器视口模拟不能标记为手机真机验收。
