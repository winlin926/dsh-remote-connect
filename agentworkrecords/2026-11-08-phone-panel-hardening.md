# 2026-11-08 手机端面板与网关加固（0.4.0）

## 背景

宿主升到 0.2.2 后手机改走宿主自己的界面，插件只剩认证网关、配对页与“远程控制”面板。用手机视口（320/390/430、深浅色、软键盘）逐个状态核过之后，面板与服务端各剩一批真实缺陷：触控目标 30–36px、设备列表在 dialog 里套滚动、软键盘弹起后输入框落在键盘下、LAN http 下复制直接抛错、弱网下 2.5s 轮询互相覆盖；服务端正相反，一条非法 close 码就能把整个宿主进程打挂。这一版把这些清掉，并把强调色收敛为一个。

## 改动

- 面板（手机）：关闭键、入口、折叠标题统一 44px；设备列表不再套内层滚动；按 visualViewport 把面板钳到键盘上方；复制走 execCommand 兜底；轮询单飞并在页面隐藏时暂停；两个对话框补可访问名称与初始焦点。
- 网关：发给手机的 close 码先规范化（1005/1006/1004 等非法值转 1011），异常时 terminate 兜底；响应一开始就撤掉 120s 空闲计时，长流不再被掐断；boot.js 带内容 ETag 并支持 304；预览能力 URL 增加 12 小时绝对寿命（原来只有 2 小时滑动闲置，持续使用可无限续期）。
- boot 脚本：撤销探测单飞且不再跟随 SSE 载体；重连按 3s→6s→…→30s 退避并在连上后归零；随机 UUID 兜底的属性可再被宿主覆盖；blob 打开的窗口断开 opener；断线遮罩改为带 aria-modal 的对话框，焦点落在唯一按钮上。
- 配对密码：入口从公网主栏移到“密码直连配对”开关下方，局域网连接的用户也能设置。
- 强调色固定为陶土橙，删掉三色选择与整套同步机制（插件不再读宿主的 `--cl-accent`）。
- 部署脚本：手机宿主默认收起侧栏，native-qa 先点“打开侧边栏”再断言入口可见。

## 验证

`pnpm typecheck` / `pnpm test`（8 文件 78 用例）/ `pnpm build` 全绿；手机全链路（配对→会话→面板→复制→撤销遮罩）在隔离宿主上跑通，配对页只保留一条设计内的 403；面板 320/390 无横向溢出、触控目标 44px、键盘钳制与剪贴板兜底实测通过。细节见 docs/verification.md。
