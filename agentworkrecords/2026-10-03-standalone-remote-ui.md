# 2026-10-03 独立远程界面（0.2.0）

## 做了什么

- 连接方式：选择模式只保存偏好，点"切换到…"才真正切换；远程设备发起切换时先收到确认再断开。
- 远程入口换成自己的界面，本机桌面和 `dsh web` 的官方界面不变。
- 界面形态参照 Claude / ChatGPT 手机客户端：圆形悬浮按钮的顶栏、带图标导航和纯文本会话列表的抽屉、胶囊形输入框（＋、会话选项、模型、发送）。配色沿用 `docs/ui-spec.md` 的暖色与陶土橙。
- 根目录 `DSH-PLUGIN-UI-SPEC.md` 为各插件共享的 UI 规格，本仓库保留副本。

## 接手后修掉的问题

宿主端：

- 局域网 IP 变化后网关拒绝新地址：改为每次请求按当前网卡地址判断。
- 二维码可能指向虚拟网卡或 TUN 地址：按网卡名和地址段排序，物理局域网地址优先。
- 设备数到 32 台后无法再配对（公网模式每次换域名都会新增设备）：淘汰最久未使用且不在线的设备。
- 宿主接口的普通 403 被当成"授权已失效"：只认网关自己的 `unpaired`。
- 公网自检连续失败就拆连接：启动验证放宽到 60 秒；连接建立后的失败只提示。
- 远程入口脚本缓存一小时，升级后可能白屏：入口与样式改为每次校验，带哈希的分片长期缓存。
- 网关转发的请求带内部标记，本机管理接口见到标记即拒绝（原来只靠路径拦截）。
- 偏好文件损坏导致插件无法加载：回退默认值并提示。

远程界面：

- 加了根级和分区错误边界，渲染异常不再整页空白。
- "其他宿主功能"不再重复列出已归类的配置。
- 键盘鼠标设备 Enter 发送、Shift+Enter 换行；触屏保持 Enter 换行；输入框随内容增高。
- 深色主题下代码块跟随主题。
- 远程停用或卸载本插件前给出确认。
- 对 rc.2 内部结构的读取集中到 `src/remote/host.ts`，带存在性检查。

电脑端面板与配对：

- 面板样式重写为紧凑的桌面风格：分段选择、小号按钮、撤销改为无框的危险色文字按钮。
- 强调色可选（陶土橙、蓝色、黑色），保存在宿主偏好里，电脑面板、配对页和手机界面共用；UI 规格升到 1.1。
- 有配对请求时在电脑上直接弹窗，侧栏图标亮提示点。
- 设备名改为"机型或系统 · 浏览器"，可重命名；记录配对时的访问地址并标明局域网 / 临时公网。
- 临时公网地址关闭后，经它配对的记录自动清除（凭据绑定在那个地址上，不可能再用）。

第二轮（按真机反馈）：

- 连接方式改成两个带说明的选项："同一 Wi‑Fi" 和 "任意网络"，去掉"固定入口"。已连接时点另一个选项只弹确认，确认后才更换；不再有"待切换"状态和"切换到…"按钮。
- 配对请求弹窗在面板打开时也弹出。
- 手机端所有系统下拉菜单换成自绘的底部选择面板；模型按供应商分组。
- 主题和强调色移到"设置与管理"顶部的"外观"。
- 附件选择器声明接受任意类型。
- 手机返回键关闭已打开的面板、抽屉或页面，不再直接离开页面。
- 凭据 cookie 从 SameSite=Strict 改为 Lax：从其他应用打开链接时不再被当成未配对；跨站请求只放行打开应用页面本身。
- 补齐宿主 Markdown 组件依赖的字体、圆角等变量，代码块使用等宽字体且不再被应用按钮样式撑开；界面主题不再被宿主的深浅色设置覆盖。
- 页面语言标为中文，浏览器不再提示翻译。
- 二维码不再列出 169.254 等手机连不上的地址。
- 新增 `scripts/phone-qa.mjs`，配合 Android 模拟器（adb reverse）做真机浏览器检查。

第三轮：

- 两次回复之间的思考和工具调用折叠成一行"N 步 …"，展开后逐条查看。
- 表格改成圆角容器、表头底色、只留横线，过宽时在容器内横向滚动。
- 文件页改成单个列表（文件夹在前），点文件名在底部面板里预览，下载是行尾的图标；文件内容兼容宿主返回的几种字节格式。
- 二维码在面板打开期间自动更新（有设备正在等待确认时不更新），并注明它只用于添加新设备。
- 配对页在浏览器愿意提供时上报手机型号（仅 HTTPS，也就是"任意网络"方式下可用）。

第四轮：

- 手机端每 6 秒向网关确认一次连接，连续两次失败就在顶部显示"和电脑的连接断开了"及原因提示；宿主的传输错误（如 HTTP 530）改成一句人话。
- 电脑侧栏展开时，远程控制入口放到账号一行的右端；折叠时保持原位。

0.2.1：

- “任意网络”可手动改用 localhost.run 线路（系统 ssh，免注册免下载）；实测很慢，不自动切换。详见 `docs/research.md`。
- 网关对文本类响应启用 gzip。
- 回复里按文件路径引用的图片通过宿主的文件路由显示。
- 会话列表长按（或右键）弹出操作：重命名、归档 / 恢复、创建分支。宿主没有删除会话的接口。
- 已有未使用的新会话时不再重复新建；未使用的会话在列表里显示为“新会话”。
- 工作区选择面板里可以直接进入工作区管理。

0.2.2：

- 电脑端代理多了“自动检测系统代理”（默认），做法与 dsh-proxy 相同：环境变量、Windows Internet 设置、macOS scutil；另有手动填写和不使用。
- 网关记住上次的端口并优先复用，“同一 Wi‑Fi”的地址在重启后不变；端口被占用时才换。
- 已配对的手机再扫新的二维码直接进入，不再产生新的配对请求。
- 点击二维码刷新、点击链接复制，去掉了两个按钮。

0.2.3：默认不使用代理（走代理时出口地址可能被 Cloudflare 拒绝，直连反而能通）；电脑端自检在代理失败时再直连试一次。

工程：`lib/` 不再提交到 git，发布流程会先构建。
