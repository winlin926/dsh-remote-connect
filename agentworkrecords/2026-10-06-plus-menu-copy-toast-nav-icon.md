# 2026-10-06 “+”菜单、复制提示、设置页图标（0.2.5）

## 背景

用户反馈三点：设置页导航里“远程控制”用的是通用齿轮，辨识度低；电脑面板点链接复制后只在底部出一行小字，以为没复制上；手机界面缺少电脑端“+”菜单里的目标、计划、反馈和压缩、权限、模型这些指令。

## 改动

- 手机界面的“+”按钮改为打开菜单。“添加”一组：文件、目标、计划、反馈；“指令”一组：压缩、权限、模型、导出，以及会话目录里的其他指令。目录来自宿主的 `commands.list`（与电脑端“/”菜单同源），宿主没有这个接口时菜单里只有“文件”。
- 一行要么直接执行（计划、压缩、导出），要么把指令写进输入框等用户补内容（目标、反馈，以及目录里带参数提示的指令）；权限打开会话选项，模型打开本页的模型选择器。
- 输入框里以会话指令名开头的一行按指令执行（`Session.command`），不再当普通消息发给模型。
- 会话里的指令节点显示为一行：指令、参数和宿主给出的结果或错误。
- 电脑面板：复制成功后在面板上方弹出“已复制配对链接”的浮层，约两秒后消失；复制失败仍在原处提示手动复制。
- 设置页导航的“远程控制”换成手机图标，做法与 Office、电脑控制两个插件相同（按标签找到该行，用 CSS 遮罩换图标）。
